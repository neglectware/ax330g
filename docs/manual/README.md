## Conventions

- A parameter name is in **bold** at its first use in a section. The manual writes each name as the plugin shows it.
- "The unit" is the original hardware: the Korg Toneworks AX30G or AX300G.
- "The plugin" is AX330G.
- "The host" is the application that loads the plugin, for example Logic Pro or MainStage.
- The glossary tells what each technical name means.

Safety and advice lines use these labels:

WARNING: A condition that can cause injury, for example damage to your ears.

CAUTION: A condition that can cause damage to equipment or loss of work.

NOTE: Information that helps you use the plugin.
