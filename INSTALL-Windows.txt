AX330G for Windows (VST3, 64-bit)
=================================

WARNING: Nobody has tested this build on a Windows computer. GitHub Actions
compiled it on a Windows build server. This shows that it compiles. It does
not show that it operates correctly. Please tell us what occurs: the plugin
loads or not, it makes sound or not, a control does the wrong thing.

The build is not signed. Windows or your host can show a warning when you
load it for the first time. This warning is expected.

To install the plugin:

1. Copy the "AX330G.vst3" folder from this zip file to this folder:

       C:\Program Files\Common Files\VST3\

   If the folder does not exist, make it. You must have administrator
   permission to copy files into Program Files.

2. Start your host again, or tell it to scan for plugins again.

3. Find the plugin under Neglectware > AX330G.

AX330G emulates the effects of the Korg Toneworks AX30G and AX300G guitar
multi-effects units (1997). It is an unofficial project. It is not
affiliated with or endorsed by Korg. The manual is at
https://github.com/neglectware/ax330g
